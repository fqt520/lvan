# Lvan 无痕去水印

浏览器里本地运行的 AI 图片去水印工具。**打开图片即自动识别并去除水印**（识别不到的用画笔涂一下）：**不留白条、不留阴影，水印以外的像素与原图逐字节一致**。图片全程不上传任何服务器。

## 自动识别水印

打开图片后自动完成「识别 → 去除」，无需手动涂抹：

1. 用 PP-OCRv4 文字检测模型（[RapidOCR](https://huggingface.co/SWHL/RapidOCR)，4.7MB）找出所有文字；
2. 判断哪些是水印：
   - 有**半透明叠加特征**的文字（α 直方图在某个不透明度处有尖峰）——抖音号、小红书号、平铺/倾斜的“样图”水印等；
   - 位于图片**四周边缘或角落**的文字——@用户名、网址、角落 Logo；
   - 画面中间的正常文字（招牌、海报标题）默认保留；设置里可改为「所有文字」。
3. 半透明水印沿笔画特征向外生长，补上 OCR 漏检的字母（倾斜、很淡的部分）；
4. 带纯色底板的 Logo（如红底白字），连同底板一起识别。

识别结果会显示为红色，可用画笔/擦除修改后再去除；所有操作都可撤销。批量处理时每张图独立识别。

> 目前自动识别针对**文字类**水印（绝大多数平台水印都是文字或文字+底板）。纯图形 Logo 可能识别不到，用画笔涂一下即可；同一位置的 Logo 可用批量处理「套用当前涂抹位置」。

## 为什么能做到“无痕”

市面上很多去水印工具/小程序会出现白条、阴影、发糊，通常是这几个原因造成的，本项目逐一解决：

| 常见问题 | 原因 | 本项目的做法 |
| --- | --- | --- |
| 整张图变糊、颜色变了 | 把整张图缩到 512×512 修复再放大 | 只裁剪水印附近区域送进模型，能用原分辨率就用原分辨率；**只把选区内的像素贴回原图**，选区外逐字节不变 |
| 水印边缘留下一圈阴影/光晕 | 选区没盖住水印的描边、投影、抗锯齿边 | 选区自动向外扩展（可调），边缘几像素羽化过渡 |
| 出现白条/黑边 | 图片不是 512 的整数倍时用白色/黑色填充 | 用**镜像填充**，模型看到的是自然延续的画面 |
| 长条文字水印修完很糊 | 一整行文字被缩得很小再放大 | 细长水印**按原分辨率分块**依次修复，后一块参考前一块的结果 |
| 半透明水印下的人脸、文字被“重画”走样 | AI 只能猜，猜不出原来的细节 | **半透明水印反向还原**：水印图 = (1−α)·原图 + α·水印色，反解出真实像素，而不是让 AI 去猜 |

### 半透明水印反向还原（智能模式）

抖音号、小红书号、平铺的“样图”文字等大多是半透明白色（或黑色）叠加，水印下面的原图信息其实还在。智能模式会：

1. 用 AI 补画结果和多种半径的形态学开/闭运算估计“水印下的背景”，通过 α 直方图的尖峰找到水印颜色和不透明度 A；
2. 用笔画两侧的真实背景像素重新校准 A；
3. 只在检测到的笔画及其 2 像素边带内，用 ICM 迭代逐像素求解 α，消除抗锯齿边缘的残影；框内其余像素保持原样——即使框选了一大片，框里的人脸也不会被改动；
4. 多重安全校验：彩色/实心 Logo、过浓的投影、还原后水印尖峰仍存在等情况，自动退回 AI 补画，**宁可重画也绝不留下水印**。

不透明的水印/Logo 则交给 [LaMa](https://github.com/advimman/lama)（big-lama）模型补画，这是目前开源里去水印/物体消除效果最好的模型之一，[IOPaint (lama-cleaner)](https://github.com/Sanster/IOPaint) 以及不少去水印小程序都在用。ONNX 模型来自 [Carve/LaMa-ONNX](https://huggingface.co/Carve/LaMa-ONNX)（Apache-2.0）。

> 说明：被**完全不透明**的水印盖住的内容在原图里已经不存在，任何工具都只能“补画”出合理的内容，无法 100% 还原；半透明水印则可以还原出非常接近原图的真实像素。

## 使用

### 在线使用（推荐）

仓库已配置 GitHub Pages 自动部署：在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**，合并到 `main` 分支后即可通过 `https://<用户名>.github.io/lvan/` 访问，手机、电脑都能用。

### 部署到自己的 VPS（国内访问更快）

在 VPS 上用 root 执行一行命令即可（Ubuntu / Debian / CentOS / Rocky / AlmaLinux）：

```bash
# 只有 IP：
curl -fsSL https://raw.githubusercontent.com/fqt520/lvan/main/deploy/install.sh | bash
# 有域名（先把域名解析到 VPS，自动申请 HTTPS 证书，推荐）：
curl -fsSL https://raw.githubusercontent.com/fqt520/lvan/main/deploy/install.sh | DOMAIN=你的域名 bash
```

脚本会安装 nginx、下载网站代码，并把 AI 模型和推理引擎**下载到 VPS 本地**（之后用户访问不再依赖 huggingface / CDN），配置多线程所需的响应头，有域名时自动配置 HTTPS。再次运行即为升级。

> 建议用域名 + HTTPS：浏览器只在 HTTPS 下才开放显卡加速和多线程，纯 IP 的 http 访问在手机上会慢很多。国内 VPS 绑定域名需要 ICP 备案；香港/海外 VPS 不需要。别忘了在云服务商的安全组里放行 80 和 443 端口。

### 本地运行

需要一个静态文件服务器（浏览器不允许直接双击 `index.html` 加载模块脚本）：

- Windows：双击 `start.bat`
- macOS / Linux：运行 `./start.sh`
- 或：`python3 -m http.server 8080`，然后打开 http://localhost:8080

### 操作

1. 点击 / 拖拽 / 粘贴（Ctrl+V）图片——自动识别并去除水印；
2. 有漏掉的：用 **画笔** 涂抹或 **框选** 框住，再点 **✨ 一键去水印**；
3. 按住 **对比** 查看原图，不满意可撤销；满意后点 **保存**（默认 PNG 无损）。

其他功能：撤销/重做、滚轮或双指缩放、空格拖动画布、批量处理同一位置的水印、调整边缘扩展。

快捷键：`A` 自动识别 · `B` 画笔 · `R` 框选 · `E` 擦除 · `H`/空格 移动 · `[` `]` 笔刷大小 · `0` 适应窗口 · `Enter` 去除 · `Ctrl+Z` 撤销 · `Ctrl+S` 保存

### AI 模型

首次使用会自动下载约 200MB 的去水印模型和 5MB 的识别模型（国内自动使用 hf-mirror.com 镜像），下载后缓存在浏览器中，之后可离线使用。下载慢的话：

- 手动下载 [lama_fp32.onnx](https://hf-mirror.com/Carve/LaMa-ONNX/resolve/main/lama_fp32.onnx)，在「设置 → 选择本地模型」中加载；或
- 自己部署时把它放到 `models/lama_fp32.onnx`（识别模型放到 `models/ch_PP-OCRv4_det_infer.onnx`），页面会优先从这里加载。

支持 WebGPU 的浏览器（新版 Chrome / Edge / Safari）会用显卡加速，否则使用多线程 CPU 推理。

## 开发

```
index.html        页面
css/style.css     样式（适配手机）
js/app.js         交互：涂抹、缩放、撤销、保存、批量
js/engine.js      模型下载/缓存、onnxruntime-web 推理（WebGPU → WASM 自动回退）
js/detect.js      自动识别水印：文字检测 + 半透明判定 + 笔画生长 + Logo 底板
js/core.js        核心：裁剪、分块、镜像填充、选区扩展与羽化、回填
js/translucent.js 半透明水印反向还原
sw.js             Service Worker：开启跨源隔离以使用多线程 WASM
deploy/install.sh VPS 一键部署脚本（nginx + 本地模型 + 可选 HTTPS）
tests/            核心算法测试：node tests/core.test.mjs
```
